## 一、装好环境

**前提**：Python 3.13（本项目在 anaconda base 环境验证通过）。
> Windows 自带的 Python 3.14 太新，PyTorch 没有对应版本，**不要用**。

打开命令行（Win+R 输入 `cmd`），逐条执行：

```bat
:: 1. 基础依赖（走清华镜像快很多）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

:: 2. PyTorch —— 必须单独装 CPU 版
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

第 2 步不能省。直接从 PyPI 装 `torch` 会拉下一个带 CUDA 的巨型包（好几个 G），
而本项目在 CPU 上跑几分钟就出结果，完全不需要 GPU。

装完可以自检：

```bat
python -c "import numpy, sklearn, matplotlib, PyQt5, torch, mne; print('依赖齐全')"
```

## 二、启动软件

**双击 `run.bat`** 就行。

它会自动找一个"真的能跑本项目"的 Python（这台机器上 anaconda 的 3.13 和别的版本共存，
挑错了会报 `import torch` 失败，所以脚本会逐个实际 import 验证一遍）。

也可以手动启动：

```bat
set PYTHONPATH=src
python -m cneeg gui
```

窗口打开后是五个标签页，**按 ①→⑤ 的顺序用**。

## 三、五步走完一次完整实验

### ① 数据

三个选项：

| 控件 | 说明 |
|---|---|
| **数据源** | `仿真数据`（默认，程序生成）/ `真实文件`（读你自己的脑电） |
| **预设** | 汉语声调（四声）/ 汉语词汇（三词）/ 英语单词（yes/or/no） |
| **受试者数、每类试次数** | 决定数据规模。默认 6×60 共 1440 试次，跑一次约 20 分钟 |
| **信噪比** | 默认 **+4 dB**。调低会让任务变难 —— 这正是"信噪比扫描"实验要考察的 |
| **随机种子** | 固定种子 = 结果完全可复现。答辩时别乱改 |

点 **生成数据**。下方会画出原始波形和类别可分性拓扑图。

> **建议**：第一次用先保持默认，直接点"生成数据"。想快速看效果就把受试者数改成 2、
> 每类试次数改成 20，一分钟就能看到结果。

### ② 预处理

| 控件 | 默认 | 说明 |
|---|---|---|
| 带通滤波 | 0.5 – 40 Hz | 去掉漂移和高频肌电 |
| 工频陷波 | 50 Hz | 中国市电频率。野外采集必开 |
| 重参考 | CAR（全脑平均） | 抑制共模噪声 |
| 时间窗 | −0.2 – 1.0 s | 刺激前 200 ms 作为基线 |
| 基线校正 | −0.2 – 0 s | 消除试次间的慢漂移 |
| 伪迹剔除阈值 | 150 µV | 超过就丢掉这个试次 |
| 标准化 | 逐通道 z-score | 让各通道量级一致 |

改完点 **应用并预览**，上方是原始波形、下方是处理后波形，可以直接对照。
剔除伪迹会让试次数变少（状态栏会显示剩多少），这是正常的。

> **注意**：这里改的参数会一路带到后面的训练。如果只改了参数却没点"应用并预览"，
> 训练用的还是上一次的数据 —— 界面会提示。

### ③ 训练

1. **选模型**：`SVM 基线` 或 `ShallowConvNet 深度学习`
2. **调超参**（右边那一栏，另一模型的参数会自动置灰）：
   - SVM：`C`（正则强度）、`gamma`、PCA 主成分数
   - CNN：训练轮数、学习率、批大小、早停耐心值
3. **交叉验证折数**：默认 5 折
4. **两个勾选框**：
   - ☐ **留一受试者评估** —— 测试折的受试者训练时完全没见过。**更严格**，
     数字通常明显更低。想看模型是不是真的学到了通用规律，就勾它。
   - ☐ **额外做置换检验** —— 打乱标签重跑 20 次。**强烈建议勾上**，
     这是证明结果不是数据泄漏的关键证据（详见技术文档）。
5. 点 **开始训练**。

训练在后台线程跑，界面不会卡死，**可以随时切到别的页**。进度条下方会实时画出
训练损失、验证宏 F1、验证准确率三条曲线。想中止就点 **取消**。

> CPU 上 SVM 约 1 分钟，CNN 约 5–15 分钟。CNN 慢是因为它要在每折里重新训练一个神经网络。

### ④ 评估

训练完成后结果会自动出现在这里。

- **指标汇总**：准确率、宏平均 F1、Cohen's κ、相对随机的提升、置换检验 p 值
- **逐类指标**：每一类的精确率 / 召回率 / F1 —— 只看总准确率会掩盖"某一类完全学不会"
- **图**：下拉框可切换混淆矩阵 / 训练曲线 / 置换检验分布 / 模型对比

右上角三个按钮：

| 按钮 | 作用 |
|---|---|
| **训练两个模型并对比** | 自动把 SVM 和 CNN 都跑一遍，出对比图。**这是立项报告要的核心结论** |
| **导出 HTML 报告** | 生成单文件报告，图片已内嵌，**直接发给老师就能打开** |
| **导出指标 CSV** | 指标表格存成 CSV（Excel 可直接打开） |

### ⑤ 推理

用训练好的模型逐试次预测，看看它在单个试次上到底怎么判断的。

1. **数据**：用当前数据集，或选一个脑电文件
2. 点 **开始预测**
3. 左表列出每个试次的预测类别、置信度、以及和真实标签是否一致（✔ / ✘）
4. **点任意一行**，右边画出那个试次的空间分布拓扑图 —— 能看出模型是靠哪些脑区做判断的

> ⚠ **这一页的"一致率"不是模型性能，别拿它当准确率。**
> 它用的是在全量数据上重训的**部署模型**（专门拿去推理用的那个），而默认输入
> 又是"当前数据集" —— 也就是它训练时用过的同一批数据，等于考自己做过的题，
> 一致率当然接近 100%。界面上已经标注了"部署模型自评，非性能指标"。
> **模型的真实性能看"④ 评估"页的交叉验证结果。**

## 四、命令行用法（不用点界面）

答辩演示、老师验收、批量跑实验时更省事。

```bat
set PYTHONPATH=src

:: 整条流水线一键跑完
run_cli.bat

:: 或者逐条来
python -m cneeg gen-data                              :: 生成数据 + 检查图
python -m cneeg train --model svm                     :: 训练 SVM
python -m cneeg train --model cnn --permutation       :: 训练 CNN + 置换检验
python -m cneeg train --model svm --group             :: 留一受试者评估
python -m cneeg compare                               :: 两模型对比 + HTML 报告
python -m cneeg sweep --snrs -12 -8 -4 0 4 8          :: 信噪比扫描
python -m cneeg infer --file "D:\data\被试01.mff"     :: 真实数据推理
python -m cneeg train --model svm --save-model        :: 存模型（infer 要用）
python -m cneeg gui                                   :: 打开界面
```

**覆盖任意配置项**（`--set 键=值`，可重复，写在子命令前后都行）：

```bat
python -m cneeg train --model cnn --set model.cnn.n_epochs=200 --set seed=7
python -m cneeg gen-data --set data.synthetic.snr_db=-6 --set data.synthetic.n_subjects=10
```

键名写错会**明确报错**，不会静默忽略。可用键见 `configs/default.yaml`。

> **关于 `infer` 的默认数据**：加了 `--file` 才是对真实文件推理。不加 `--file`
> 时它会对一段自带的 120 秒演示录音做预测 —— 那段录音跟训练数据没关系，
> 所以跑出来的数字高或低都不能说明模型好坏，命令输出里也会提醒这一点。
>
> **为什么那段演示录音上结果特别差**（低到 0% 都可能）？因为它相当于一个
> **全新的受试者**：仿真生成器给每个受试者一套独立的随机空间投影，演示录音
> 用的是训练时没出现过的那一套。模型在没见过的空间分布上会明显退化 ——
> 这正是"留一受试者评估"（`--group`）要量化的那个差距，不是模型坏了。
> 真实数据也有类似情况：换一个被试，准确率通常会掉不少。

## 五、用你自己的脑电数据

### 方法一：改配置（推荐）

编辑 `configs/default.yaml`：

```yaml
data:
  source: "file"                      # synthetic → file
  file:
    path: "D:/data/被试01.mff"        # 指向你的文件
```

### 方法二：命令行指定

```bat
python -m cneeg train --model cnn --file "D:/data/被试01.mff"
```

### 支持的格式

`.mff`（EGI NetStation）、`.vhdr`（BrainVision）、`.edf`、`.bdf`、`.cnt`、
`.set`（EEGLAB）、`.fif`（MNE）。按扩展名自动识别。

### 和 PsychoPy 打标对齐

如果记录里没有内嵌事件轨，可以读 PsychoPy 导出的试次日志来还原每个试次的起始时刻：

```yaml
data:
  file:
    path: "D:/data/被试01.mff"
    marker_log: "脑电实验/data/trials_20260913_160740.csv"
```

系统会读日志里的 `word_onset_s` 列，换算成采样点索引当事件 onset。

### 通道名要对得上

预处理里的拓扑图需要标准 10-20 通道名（`Fz`、`Cz`、`Pz`…）。
如果你的文件用的是 `E1`/`E2` 这类编号（EGI 默认），在配置里指定
`data.file.montage`，或先用 MNE 改好通道名。

## 六、结果文件都在哪

跑完之后，`data/` 目录下：

```
data/
├── processed/   预处理后的数据集（.npz，可被 --data 参数复用）
├── figures/     图表 PNG
│   ├── 01_原始波形.png
│   ├── 02_各类ERP.png
│   ├── 03_类别可分性拓扑.png
│   └── 信噪比扫描.png
├── reports/     结果输出
│   ├── report_*.html     HTML 报告（单文件，图片内嵌）
│   └── results_*.json    指标数据（机器可读）
└── models/      训练好的模型（.joblib）
```

**`models/` 只有加了 `--save-model` 才会生成**。普通训练不写模型文件 ——
交叉验证那些指标来自"没见过测试折"的折模型，跟最终要拿去推理的模型不是一回事，
所以不会自动落盘。想让 `infer` 能用，训练时明确存一次：

```bat
python -m cneeg train --model svm --save-model
python -m cneeg infer --file "D:/data/被试01.mff"
```

存下来的是**在全量数据上重训**的模型（界面里"推理"页用的也是它）。
按上面的命令做，`infer` 会自动找到 `data/models/model.joblib`。

**HTML 和 JSON 各有各的用处**：报告是给人看的，可以直接发给老师；
JSON 里存着**逐折**的准确率与 F1，是给程序用的 —— 想重新画图、
把结果并进论文表格，或者对比两次实验的差异，都得靠它。
只看报告里的"均值 ± 标准差"是做不了逐折比较的。

JSON 里主要有哪些字段：

| 字段 | 含义 |
|---|---|
| `accuracy_mean` / `accuracy_std` | 各折准确率的均值与标准差 |
| `accuracy_sem` | 均值的标准误（std ÷ √折数），比较两个模型时用它 |
| `folds[]` | **每一折**的准确率、宏 F1、κ —— 逐折比较靠这个 |
| `per_class` | 每个类别的精确率、召回率、F1 |
| `permutation` | 置换检验的零分布与经验 p 值（跑了才有） |
| `is_synthetic` | 该结果是否来自仿真数据 |

**所有仿真数据跑出来的图表右下角都带"仿真数据"水印**，HTML 报告顶部也有红色警示横幅 ——
防止有人把仿真结果误当成真实实验结论。真实数据则显示绿色"真实数据"标记。

## 七、出错怎么办

| 现象 | 原因与解决 |
|---|---|
| `ModuleNotFoundError: No module named 'torch'` | `pip install torch --index-url https://download.pytorch.org/whl/cpu` |
| `ModuleNotFoundError: No module named 'PyQt5'` | `pip install PyQt5` |
| `ModuleNotFoundError: No module named 'mne'` | `pip install mne` |
| 双击 `run.bat` 闪一下就没了 | 说明没找到可用的 Python。用 `cmd` 手动跑一遍，看具体报错 |
| 图上中文变成方框 | 系统缺微软雅黑/黑体。检查 `C:\Windows\Fonts\msyh.ttc` 是否存在 |
| `OMP: Error #15` | anaconda MKL 与 pip 版 PyTorch 的 OpenMP 冲突。`run.bat` 已自动设置 `KMP_DUPLICATE_LIB_OK`；手动跑时自己设一下 |
| CNN 准确率就是 25%（等于随机） | 信噪比太低。默认 +4 dB 是标定过的，手动调低后 CNN 会先崩 —— 这本身就是要考察的结论 |
| 训练很久没反应 | 命令行下输出会被缓冲，看起来像卡住。加 `-u`：`python -u -m cneeg train ...` |
| `--set` 写的参数好像没生效 | 键名写错会当场报错。对着 `configs/default.yaml` 检查拼写 |
